# About Me

サイトURL: https://fk-techw.github.io/about-me/

このサイトは、自分がどんな人間かをざっくり知ってもらうために作りました。
構成は、自己紹介ページと、趣味の野球について語るページの2本立てです。
最初は白基調のシンプルなデザインで作っていましたが、途中で「あたたかみのある見た目にしたい」と思い、クリーム色の背景と赤・深緑を差し色にしたデザインに作り変えました。

# 課題の紹介

## TOP
- 開いてすぐ「ようこそ、私の自己紹介サイトへ」という一文と、このWebサイトの特徴である球場の写真を大きく見せる構成にした
- その下に「このサイトで分かること」「特に見てほしいページ」の2枚カードを置いて、サイト全体の見取り図がすぐつかめるようにしました
- デザインのお手本はApple公式サイトのようなシンプルで清潔さを意識するところから始めたが、最終的には赤みのある差し色とクリーム系の背景を使った、あたたかみのある雰囲気に寄せた

## 自己紹介のページ
- 名前・出身・好きなことのリストに加えて、「ひとこと」という一言メッセージと、興味関心を並べたタグ(chips)を追加した
- 情報を詰め込みすぎず、リスト＋一言＋タグの3構成で、短時間でも人柄が伝わるようにした

## 野球のページ
- 野球を好きになったきっかけ、応援しているチーム(阪神タイガース)、好きな選手(佐藤輝明選手)を紹介するセクションに加えて、「阪神の好きなところ」を語るカードを追加した
- さらに「思い出に残っている試合」というセクションを作り、印象に残っている試合を具体的なエピソードとして書けるようにした
- 背景をグラウンドをイメージした深緑色に変えて、他のページと空気を変えた。変わり映えしないと飽きてしまうので「違うページになったんだ」という感じが出したかった

# 一番見てほしいところ

野球ページの「思い出に残っている試合」。ただ好きなチームや選手を並べるだけでなく、自分が実際にこれまで球場での現地観戦やテレビでの観戦で見て感じたことを書いたので、一番自分らしさが出ていると思う。あとTOPページの2枚カード([このサイトで分かること][特に見てほしいページ])で、サイト全体を迷わず見れるように工夫した。

# 力を入れた点

## 実装面
- 全ページ共通のサイドバーをCSSの`position: fixed`で実装し、どのページを開いていても同じ操作感になるようにした
- TOPページの「2枚カード」「リンクカード」など、似たようで少しずつ違うカードUIをいくつも作ったので、CSSのクラス名や余白のルールを整理し、実装するのが大変だった
- アイコンはFont Awesomeというサイトを使って`<i class="fa-solid fa-◯◯">`で表示する形にした。これにより画像ファイルを用意しなくて済むので楽ではあった。

## デザイン面
- 背景が最初は真っ白だったのでそれではもの足りないし、面白くないと思い、真っ白よりもあたたかみのある印象の色にした。
- ページの区切りに、野球の縫い目をイメージした点線カーブを入れて、なにげない場所にも野球要素を混ぜ込んだ
- 難しかったのは、前述にもある通り、白基調のシンプルなデザインから今の配色に変えるときに、文字の読みやすさを保ったまま雰囲気を変えること。特に野球ページの深緑色の背景で、文字の色やその他いろんなところの色は何度も調整した
