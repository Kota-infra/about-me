このサイトは、自分がどんな人間かをざっくり知ってもらうために作りました。
自己紹介ページと、趣味の野球について語るページの2本立てです。
シンプルなサイト構成にしたかったので、余計な演出は削って、Appleの公式サイトのような「白多め・余白多め」の雰囲気にしています。

# 課題の紹介

## TOP
- 開いてすぐ「ようこそ」とだけ出して、そこから自己紹介・野球ページに進めるシンプルな構成にした
- 右に固定のサイドバーを置いて、どのページからでもすぐ移動できるようにした
- デザインのお手本はApple公式サイト。色数を絞って、フォントの太さと余白だけで「ちゃんと作ってる感」を出すのを意識した

## 自己紹介のページ
- 名前・出身・好きなことを、シンプルなリスト形式で紹介するページ
- 情報を詰め込みすぎず、あえて余白を残して見やすさを優先した

## 野球のページ
- 野球を好きになったきっかけ、応援しているチーム(阪神タイガース)、好きな選手(佐藤輝明選手)を紹介するページ
- 背景をグラウンドをイメージした深緑色に変えて、他のページと空気を変えた。「野球の話に入った」感じが出したかった

# 一番見てほしいところ

野球ページの背景色が切り替わるところ。単なる色替えだけど、ページごとにテーマを変えることで「ここからは趣味の話です」という区切りを演出できたと思う。あとサイドバーで今どのページにいるか一目でわかるようにしてあるので、そのへんの使いやすさも見てほしい。

# 力を入れた点

## 実装面
- 全ページ共通のサイドバーをCSSの`position: fixed`で実装し、どのページを開いていても同じ操作感になるようにした
- 画面幅が狭いとき(スマホ)は、サイドバーが上部の横並びバーに切り替わるようにレスポンシブ対応した
- 難しかったのは、PC表示とスマホ表示でスタイルを出し分ける`@media`の範囲管理。閉じ忘れで意図せずPC表示までスマホ用のレイアウトが適用されてしまうバグにハマったので、CSSの構造をちゃんと整理する大事さを学んだ
- アイコンはFont Awesomeというサイトを使って`<i class="fa-solid fa-◯◯">`で表示する形にした。画像ファイルを用意しなくて済むので楽だった

## デザイン面
- お手本にしたApple公式サイトのように、色数を絞って(白・グレー・差し色の赤のみ)統一感を出すことを意識した
- ページの区切りに、野球の縫い目をイメージした点線カーブのSVGを入れて、さりげなく野球要素を混ぜ込んだ
- 難しかったのは「シンプルにする」と「情報を詰め込みすぎない」のバランス。最初は色々足したくなったが、削ることを意識して今の形に落ち着いた
