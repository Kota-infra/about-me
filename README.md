サイトURL: (公開したらここにURLを貼る)

このサイトは、自分がどんな人間かをざっくり知ってもらうために作りました。
自己紹介ページと、趣味の野球について語るページの2本立てです。
最初は白基調のシンプルなデザインで作っていましたが、途中で「あたたかみのある見た目にしたい」と思い、クリーム色の背景と赤・深緑を差し色にしたデザインに作り変えました。

# 課題の紹介

## TOP
- 開いてすぐ「ようこそ、私の自己紹介サイトへ」という一文と、このWebサイトの特徴である球場の写真を大きく見せる構成にした
- その下に「このサイトで分かること」「特に見てほしいページ」の2枚カードを置いて、サイト全体の見取り図がすぐつかめるようにしました
- ページ下部に「最近のトピック」という更新ログを置いて、サイトが動いている感じを出した
- デザインのお手本はApple公式サイトから出発したが、最終的には赤みのある差し色とクリーム系の背景を使った、もう少しあたたかみのある雰囲気に寄せた

## 自己紹介のページ
- 名前・出身・好きなことのリストに加えて、「ひとこと」という一言メッセージと、興味関心を並べたタグ(chips)を追加した
- 情報を詰め込みすぎず、リスト＋一言＋タグの3構成で、短時間でも人柄が伝わるようにした

## 野球のページ
- 野球を好きになったきっかけ、応援しているチーム(阪神タイガース)、好きな選手(佐藤輝明選手)を紹介するセクションに加えて、「観戦スタイル」「阪神の好きなところ」を語るカードを追加した
- さらに「思い出に残っている試合」というセクションを作り、印象に残っている試合を具体的なエピソードとして書けるようにした
- 背景をグラウンドをイメージした深緑色に変えて、他のページと空気を変えた。「野球の話に入った」感じが出したかった

# 一番見てほしいところ

野球ページの「思い出に残っている試合」。ただ好きなチームや選手を並べるだけでなく、自分が実際に見て感じたことを書いたので、一番自分らしさが出ていると思う。あとTOPページの3枚カード([このサイトで分かること][特に見てほしいページ][今後の更新予定])で、サイト全体を迷わず案内できるようにした工夫も見てほしい。

# 力を入れた点

## 実装面
- 全ページ共通のサイドバーをCSSの`position: fixed`で実装し、どのページを開いていても同じ操作感になるようにした
- 画面幅が狭いとき(スマホ)は、サイドバーが上部の横並びバーに切り替わるようにレスポンシブ対応した
- TOPページの「3枚カード」「リンクカード」「更新ログ」など、似たようで少しずつ違うカードUIをいくつも作ったので、CSSのクラス名や余白のルールを整理しながら実装するのが大変だった
- アイコンはFont Awesomeを使って`<i class="fa-solid fa-◯◯">`で表示する形にした。画像ファイルを用意しなくて済むので楽だった

## デザイン面
- 背景にradial-gradientで淡い色のにじみを入れて、単色ベタ塗りよりもあたたかみのある印象になるようにした
- フォントをZen Kaku Gothic Newに変更し、見出しの太さ(900)と本文の細さのコントラストで、メリハリのある見た目にした
- ページの区切りに、野球の縫い目をイメージした点線カーブのSVGを入れて、さりげなく野球要素を混ぜ込んだ
- 難しかったのは、白基調のシンプルなデザインから今の配色に変えるときに、コントラスト(文字の読みやすさ)を保ったまま雰囲気を変えること。特に野球ページの深緑の背景で、文字色や罫線の色味を何度も調整した
